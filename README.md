# Prueba Técnica: Gestión de Ventas
 
Descripción
Aplicación web para la gestión de ventas, donde podrás registrar ventas, consultar ventas por fechas, mostrar totales, generar gráficos de barras por producto, y exportar los datos a Excel o PDF.

Tecnologías utilizadas:
PHP (PDO para manejo de base de datos)
MySQL (Base de datos)
Bootstrap (Diseño responsivo)
AJAX (Consultas dinámicas)
Chart.js (Gráficos)
PHPExcel (Exportar a Excel)
TCPDF (Exportar a PDF)

La aplicación permite calcular y mostrar el total de ventas realizadas en un periodo específico. Este cálculo se puede visualizar en la interfaz después de realizar una consulta por fechas.
